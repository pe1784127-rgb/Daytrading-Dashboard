DAYTRADING DASHBOARD – iPad PWA

Damit die Seite auf dem iPad wie eine App zum Home-Bildschirm hinzugefügt werden kann,
muss dieser Ordner über eine normale HTTPS-Webadresse geöffnet werden.

Enthalten:
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

Nach dem Hochladen:
1. Die Webadresse in Safari auf dem iPad öffnen.
2. Auf das Teilen-Symbol tippen.
3. "Zum Home-Bildschirm" auswählen.
4. "Hinzufügen" tippen.

Danach öffnet sich das Dashboard im App-Modus und funktioniert nach dem ersten Laden
auch offline.

Wichtig:
ChatGPT kann nicht selbst auf deinen iPad-Home-Bildschirm zugreifen oder die App dort installieren.
